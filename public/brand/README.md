# PiScrow Brand System

Core assets:

- `piscrow-app-icon.svg`
  - primary product mark for app shells, store-style surfaces, and profile cards
- `piscrow-favicon.svg`
  - simplified browser-tab mark
- `piscrow-bot-avatar.svg`
  - Telegram-ready avatar for `@PiScrow_bot`
- `piscrow-wordmark.svg`
  - horizontal lockup for docs, hero surfaces, and product listings
- `piscrow-splash.svg`
  - presentation and loading-screen splash mark

Brand direction:

- base background: deep navy / near-black
- accents: warm gold and electric violet
- symbol meaning: PiScrow holds value between two protected sides until release

Recommended usage:

- app header / metadata: app icon + wordmark
- Telegram bot: bot avatar
- browser favicon: favicon mark
- README / portfolio / deck: splash or wordmark
