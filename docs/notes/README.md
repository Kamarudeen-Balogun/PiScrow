# Notes

Use this folder for handwritten project notes.

Recommended use:

- architecture notes
- flow summaries
- investigation notes
- bug deep-dives
- return-to-project checklists

Do not use `graphify-out/obsidian/` for long-term handwritten notes because that
folder is generated output and can be regenerated at any time.

Suggested starting files:

- `index.md`
- `admin-release-flow.md`
- `trade-lifecycle.md`
- `telegram-linking.md`
